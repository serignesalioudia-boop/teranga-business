## Scène 7 — Architecture Technique

**Durée :** 60 secondes
**Type :** Animation (diagrammes + code)

### Visuel

**Partie A — Stack Technique (20s)**
- Animation des logos qui s'empilent :
  - Next.js 16 (React 19)
  - TypeScript 5.9
  - Tailwind CSS 4 + shadcn/ui
  - PostgreSQL 17
  - Prisma 7 (ORM)
  - Auth.js (JWT)
  - Cloudinary (images)
  - Docker (déploiement)

**Partie B — Schéma de la base de données (20s)**
- Diagramme simplifié des 26 modèles :
  - User → SellerProfile → Store
  - Product → Category (hiérarchique)
  - Order → SubOrder → OrderItem (multi-vendeur)
  - Payment → PaymentSplit (répartition automatique)
  - Commission (calcul en basis points)

**Partie C — Flux d'un ordre (20s)**
- Animation du parcours :
  1. Client passe commande
  2. Système split en SubOrder par vendeur
  3. Chaque vendeur reçoit sa part
  4. Commission calculée automatiquement
  5. Livraison assignée selon les règles

### Voix-off

🇫🇷 :
> "Teranga Business repose sur des technologies modernes et performantes.
> Next.js pour le framework, TypeScript pour la fiabilité, PostgreSQL pour la base de données,
> et Prisma comme ORM. Le tout conteneurisé avec Docker.
> La base de données compte 26 modèles, gérant les commandes multi-vendeurs
> avec répartition automatique des paiements et calcul des commissions."

🇸🇳 :
> "Teranga Business dafa dugal ci yeneen technologies yu am solo.
> Next.js ngir framework, TypeScript ngir sécurité, PostgreSQL ngir database,
> te Prisma ngir ORM. Te yépp ci Docker.
> Database bi am 26 modèles, tegsi commandes multi-vendeurs
> ak répartition automatique xaalis te calcul commissions."

### Storyboard

| Frame | Visuel | Durée |
|---|---|---|
| 7.1 | Logos tech stack (animation empilée) | 0-20s |
| 7.2 | Schéma BDD (diagramme simplifié) | 20-40s |

## Instructions de capture

### Écrans à enregistrer (Screencast)

1. **Homepage** — `/` (défilement complet)
2. **Page catégories** — `/categories`
3. **Page produit** — `/product/[slug]` (avec galerie, avis)
4. **Page panier** — `/cart`
5. **Page checkout** — `/checkout` (étapes)
6. **Page login** — `/login`
7. **Page register** — `/register`
8. **Dashboard client** — `/account`
9. **Historique commandes** — `/account/orders`
10. **Suivi livraison** — `/account/deliveries/[id]`
11. **Dashboard vendeur** — `/seller`
12. **Gestion produits vendeur** — `/seller/products`
13. **Formulaire création produit** — `/seller/products/new`
14. **Revenus vendeur** — `/seller/revenue`
15. **Dashboard admin** — `/admin`
16. **Gestion utilisateurs** — `/admin/users`
17. **Gestion produits admin** — `/admin/products`
18. **Commissions** — `/admin/commissions`
19. **Catégories** — `/admin/categories`

### Données de démo nécessaires

Le script `prisma/seed.ts` doit être exécuté pour avoir des données réalistes :
- Produits avec images (Cloudinary)
- Commandes avec différents statuts
- Utilateurs (clients, vendeurs, admin)
- Avis et catégories

### Annotations vidéo

Pour chaque screencast, ajouter :
- **Flèches animées** pointant vers les éléments importants
- **Encadrés de texte** avec les noms des fonctionnalités
- **Zoom lent** sur les zones clés (prix, boutons, graphiques)
- **Sous-titres FR/Wolof** synchronisés avec la voix-off

### Paramètres de recording recommandés

- **Résolution :** 1920x1080 (Full HD)
- **FPS :** 30fps (suffisant pour du screencast)
- **Format :** MP4 (H.264)
- **Ratio écran :** 16:9
- **Police sous-titres :** Montserrat ou Inter (modernes, lisibles)
